# Challenge 1 - Console auction simulator

Plain JavaScript, no frameworks, no installs. Node's built-in test runner checks your work.

```powershell
cd exercises/01-js-auction-simulator
node --test            # run all tests
node --test --watch    # re-run on save
node demo.js           # see your simulator in action
```

Open `simulator.js` and implement each function marked `TODO`. Start with `createAuction` and make one test pass at a time.

The full brief and hints are in [docs/CHALLENGES.md](../../docs/CHALLENGES.md#challenge-1---console-auction-simulator-javascript).
